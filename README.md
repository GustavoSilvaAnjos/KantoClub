# Kanto Club

Site responsivo e estático para organizar uma comunidade de Pokémon Fire Red.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main`, pasta `/ (root)` e clique em **Save**.
6. Aguarde alguns minutos; o GitHub mostrará o endereço público.

## Importante sobre os dados
Esta versão usa `localStorage`: os dados ficam apenas no navegador e aparelho em que foram criados. O link é público, mas alterações feitas por um amigo não aparecem automaticamente para os demais. Para dados compartilhados, será preciso conectar um banco como Supabase ou Firebase.
